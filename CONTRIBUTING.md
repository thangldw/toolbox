# Contributing / Đóng góp / コントリビューション

- **English:** Keep each utility focused, local-first and reversible. Add tests for filesystem behavior and require previews for destructive actions.
- **Tiếng Việt:** Giữ từng tiện ích gọn, local-first và có thể hoàn tác. Thêm test cho filesystem và bắt buộc xem trước thao tác phá hủy.
- **日本語:** 各ツールを小さくローカル優先・復元可能に保ち、ファイル操作の test と破壊的操作の preview を必須にしてください。
