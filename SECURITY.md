# Security / Bảo mật / セキュリティ

- **English:** Report vulnerabilities privately through GitHub Security Advisories and remove personal filesystem paths from evidence.
- **Tiếng Việt:** Báo lỗ hổng riêng tư qua GitHub Security Advisories và xóa đường dẫn cá nhân khỏi evidence.
