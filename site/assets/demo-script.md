# Toolbox 45-second Demo Script

Use the exact ad-hoc-signed, unnotarized `v2.0.0` public release with a disposable, harmless installer fixture and disposable developer-project fixtures. Keep all personal paths out of frame, and do not present the build as Apple-notarized or Gatekeeper-approved.

| Time | Screen action | Voiceover |
| --- | --- | --- |
| 0–5s | Open Home, then Change Timeline. | “Toolbox shows what changed on your Mac before you decide what to clean.” |
| 5–12s | Drop the signed fixture into Install Trace and start. | “Drop a DMG, PKG, or app. Toolbox saves a local before snapshot, then opens the normal macOS installer flow.” |
| 12–20s | Complete the harmless install and press Finish Trace. | “After installation, it compares filesystem metadata and FSEvents—no document contents or telemetry.” |
| 20–28s | Expand one created path and choose Review in Storage. | “Every path keeps its evidence. Reviewing never selects or deletes it automatically.” |
| 28–36s | Open Projects, select one disposable artifact, confirm Move to Trash. | “Known rebuildable output appears only inside roots I selected, and cleanup is revalidated at confirmation.” |
| 36–43s | Open Recovery, select the action, show the checks, restore. | “Trash paths stay linked, and restore refuses to overwrite an existing destination.” |
| 43–45s | Return to Home privacy line. | “Local-first, open source, and built for review before action.” |

Recording requirements: 1270×760 or 2540×1520, 30–60 seconds, no notifications, no private paths, no jump cut that hides a confirmation, readable cursor movement, and final frame on the privacy boundary.
