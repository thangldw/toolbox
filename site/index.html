START WITH A REAL TASK

Your Mac, with evidence.

Toolbox brings the former Diskora and Changeora workflows together. Inspect first, understand the result, then decide what to do.

01

Trace an installation

Capture a before snapshot, run the normal macOS install or uninstall yourself, and compare the after evidence. Toolbox observes changes; it does not execute your installer.

02

Review storage

Inspect folder allocation, hash-verified duplicate candidates, similar-photo candidates and developer storage. Select the targets you actually want to clean.

03

Recover an action

Eligible reviewed files move to macOS Trash. Recovery retains original and Trash paths and refuses to overwrite an existing destination.

INSIDE THE APP

From finding to reviewed action.

Understand what changed

Observe bounded filesystem events around a user-run workflow. Keep snapshots and evidence locally so you can revisit the result.

Inspect applications

Review installed apps and evidence-linked leftovers. Receipts and registration metadata provide context for your decision.

Focus on rebuildable artifacts

Choose a project root and inspect recognized outputs such as node_modules, .build, .venv, target, Pods and Gradle or Flutter output.

Keep control of cleanup

Every mutation requires foreground review and immediate path revalidation. Scheduled runs scan and notify only.

PRIVACY BY DESIGN

Your scan results stay on your Mac.

Snapshots, hashes, activity and recovery manifests are stored locally. No accounts, telemetry or content uploads. Full Disk Access is optional and expands readable coverage.

The built-in network request checks GitHub for a newer release only when you choose Check for Updates; it sends no scan data or file paths.

CURRENT STABLE RELEASE · v2.0.0

Download. Verify. Open.

macOS 13 or later. The DMG contains Apple Silicon and Intel slices; a physical Intel launch test is not claimed in the release record.

Download Toolbox-2.0.0.dmgSHA-256 checksum
  1. Download the DMG and checksum into the same folder. Verify with shasum -a 256 -c Toolbox-2.0.0.dmg.sha256.
  2. Open the DMG, read “Open Toolbox - First Launch.html”, and drag Toolbox to Applications.
  3. Try opening once. If blocked, use System Settings → Privacy & Security → Open Anyway, then authenticate.
