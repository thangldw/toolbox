Privacy

Toolbox is designed to explain local changes without turning your Mac into a data source.

The macOS app

Toolbox has no account system, telemetry SDK, analytics event stream, advertising identifier, remote content upload, or privileged helper. Scans, file paths, snapshots, change evidence, cleanup history, and recovery records stay on your Mac.

Toolbox reads filesystem metadata for folders and installers you explicitly select. It does not read document contents for Install Trace. Cleanup is never automatic: targets are reviewed, revalidated, and moved to Trash only after confirmation.

Network access

The app makes no automatic update request. When you press Check for Updates, Toolbox sends a GET request only to api.github.com/repos/thangldw/toolbox/releases/latest. It sends no paths, evidence, scan results, or device fields.

Opening an installer, source link, or support link hands the URL to macOS. The destination service then applies its own privacy terms.

This website

This static site currently uses no cookies, tracking pixels, analytics, forms, or third-party JavaScript. GitHub Pages and GitHub download infrastructure may retain standard service logs under GitHub’s policies.

If cookieless aggregate analytics are added later, this page will name the provider, fields, retention, and opt-out before collection begins. In-app telemetry will remain absent unless the product and this notice are explicitly changed.
